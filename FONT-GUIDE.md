# The Salt Origin — Locked Public Typography

Reference source: approved prototype and the “Himalayan Pink Salt, refined for global commerce.” heading.

## Public website fonts
- Main editorial headings: **Cormorant Garamond**, weight **500**, normal style, black/charcoal.
- Editorial accent words: **Cormorant Garamond**, weight **500**, **italic**, wine red `#9F1738` / `#A5183B`.
- Secondary editorial headings: **Cormorant Garamond**, weight **500–600**.
- Product/card titles: **Cormorant Garamond**, weight **600**.
- Body text, navigation, labels, buttons, forms: **Inter**, weights **400–800**.

The V6.7 CSS hard-locks the public main heading font family and weight so older CMS font-family values cannot accidentally change the approved typography. Content and other CMS-managed styling remain editable.
