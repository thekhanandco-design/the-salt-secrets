LOCAL CHECK
===========

Copy the current production .env.local into this folder. Do not upload or commit that file.

In the same Supabase project, run:
  supabase/THE-SALT-ORIGIN-LIVE-CMS.sql

Only when old prototype records already exist, review and optionally run:
  supabase/REMOVE-LEGACY-PROTOTYPE-DATA.sql

Then run:
  npm install
  npm run dev

Website:
  http://localhost:3000

CMS:
  http://localhost:3000/admin/login

LIVE DATA RULE
==============

GA4, Search Console, email, WhatsApp, AI, storage and social services use real environment variables and real connected records.
When credentials, permissions or records are missing, the CMS shows Connection Required, zero or an empty state. It does not create substitute records.

CURRENT UPDATE
==============

- Public product detail pages have a dedicated CMS editor at Products & Detail Pages.
- The old product quotation form and the OEM / Bulk / 100% cards were removed from product detail pages.
- Product Commercial Sheet now saves inside page_content and no longer depends on product_commercial_terms.
- Quotation and AI Email Reply workflows read the saved Product Commercial Sheet.
- Website Visual Editor uses a direct same-origin full-page preview.
- Daily Blog automation researches and prepares one blog plus one SEO article at 06:00 UTC.
- Daily Social automation researches one shared topic and image, then prepares platform-specific drafts at 06:30 UTC.
- OpenAI image generation requires OPENAI_API_KEY and OPENAI_IMAGE_AUTOGENERATE=true.
- Vercel Cron requires CRON_SECRET in production.
- Social Profile Links can be managed at /admin/social-links and enabled links appear automatically in the public footer.
- Nothing generated by AI is published before human approval.
