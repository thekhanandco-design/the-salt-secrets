# The Salt Origin — V6.6 Unified Typography & Visual Polish

This release uses `prototype2/index.html` as the visual typography source of truth.

## Typography lock
- Display headings: Cormorant Garamond
  - Main H1: 500
  - Section H2/H3: 600
  - Editorial pink accent: italic 500
- Body, navigation, buttons, forms and metadata: Inter

## Public-site changes
- Homepage hero defaults normalized to `Himalayan Pink Salt,` + italic `refined for global commerce.` when legacy default hero copy is detected.
- Homepage Private Label image collage replaced by the Private Label Atelier panel from the approved prototype direction.
- Floating Private Label labels have high-contrast dark glass backgrounds so white copy remains readable.
- Blog hero typography reduced to the approved prototype scale and weight.
- Product-detail typography and panels unified with the public site theme.
- Premium hover lift added to cards and subtle hover zoom added to visual media.

## Functional preservation
- No API route files were changed from V6.5 (45/45 route files hash-identical).
- Existing CMS, AI, Supabase, publishing, quote and integration logic is preserved.
