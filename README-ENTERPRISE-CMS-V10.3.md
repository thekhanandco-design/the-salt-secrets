# The Salt Origin Enterprise CMS V10.3

## Install
1. Extract into a new folder.
2. Copy your existing `.env.local` into the project root.
3. Run `supabase/ENTERPRISE-CMS-V10.3.sql` after the V10.2 migration.
4. Run:

```bash
npm install
npx tsc --noEmit
npm run dev
```

## Included in V10.3
- Premium brand-matched login page
- Unified thin uppercase module headings and pink-only gradients
- Compact dashboard priority cards
- Light theme fixes for Images Manager and Text Manager
- Separate Admin Articles page
- Automatic daily blog/article generation when editorial pages open
- Automatic daily social campaign preparation when Social Studio opens
- Runtime language refresh after translation selection
- Product/category/inquiry/workflow/settings button consistency
- Full-page A4 letterhead background support
- Saved-document search by number, buyer, status and type
- GA4 connection test button

## Important
The uploaded full-page letterhead should be a PNG/JPG in A4 ratio. The background is printed behind the document content.
