# The Salt Origin — Final Theme + Functional CMS Sync

This package keeps the real New Theme production project as the functional base and applies the approved website/CMS presentation without replacing live backend workflows with prototype logic.

## Preserved working systems
- Existing Next.js API routes and Supabase SQL/migrations are preserved.
- Existing authentication, leads, quotations, content generation, blog publishing, social workflows, analytics/integrations and storage architecture remain in place.
- Environment secrets are intentionally not bundled. Deploy to the existing Vercel project to keep its saved environment variables.

## CMS editing upgrades
- Text Manager supports page/section editing plus font family, size, weight, italic, underline, text/highlight color, alignment, case, letter spacing and line height.
- Split/accent hero text can be styled independently (including italic/color treatment).
- “Scan Live Page A–Z” can discover additional visible text on the selected public page and add it to Text Manager.
- Visual Editor supports section visibility, ordering, minimum height and top/bottom spacing.
- Images Manager supports page/section filtering, current-live preview, Upload/Replace, AI image creation, ALT text, Hide/Show and Reset.

## Public presentation
- Website and admin use the approved Cormorant Garamond + Inter visual language and rose/wine/charcoal palette.
- Public-facing CMS/prototype/instructional wording has been removed.
